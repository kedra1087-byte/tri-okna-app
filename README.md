# Три окна

Таверна «Три окна» для телефона. Первый заход — короткий въезд в зал: «Шестеро уже сели за столы», затем два экрана — у кого какая тема и как здесь спрашивают. Их можно пропустить. Затем спрашивают имя и день рождения и запоминают их.

Главный экран — зал. Сверху карта дня: она переворачивается прямо в виджете и не тратит расклад. Ниже полоса «вернуться к столу», если сегодня или вчера уже был расклад. Дальше шесть столов, у каждого своя тема:

- Нерра — любовь, 3 или 5 карт;
- Ирис — ситуация, 1 или 3 карты;
- Соль — работа и деньги, 3 или 5 карт;
- Каэль — саморазвитие, 3 карты. Первой лежит карта солнечного знака, при ней назван декан рождения, две другие карты — на сам вопрос;
- Линь Цзин — выбор, Книга перемен: три монеты, шесть касаний. Каждый бросок — своё касание; монеты крутятся в воздухе по отдельности, разными дугами. После падения видно сумму 6–9, три стороны и имя черты; линия ложится в знак снизу вверх. «Знак на вопрос» или «сейчас и перемена». Пока стол открыт; позже его можно закрыть платно (`locked` в `heroes.js`).
- Эйнар Хольт — последняя плитка, «как пойдёт», старший футарк: одна руна или три норны. На столе только речные камни с резью, без карточки (`site/assets/runes/`). Пока стол открыт; `sku` и цена уже стоят, замок можно включить позже.

Все шесть столов сейчас бесплатны. Замок в коде остался: если позже какой-то стол станет платным, ему ставят `locked: true`, `sku` и `price` в `heroes.js`. Внизу меню из четырёх вкладок: Зал, Журнал, Колода, Вы.

За столом выбирают число карт, берут готовый вопрос по теме стола (до пяти) или пишут свой ниже и кладут карты. Они ложатся рубашкой вверх, гость открывает их касанием или кнопкой «Открыть все». Когда открыты все, под картами появляется ответ, а ниже — уточнения: таролога можно спросить ещё трижды по тем же картам. Уточнения расклад не тратят. Новый расклад кладётся только после подтверждения. Всё записывается в журнал, и из журнала стол можно открыть снова.

За день одному гостю колода ложится трижды. Карта дня и уточнения в этот счёт не входят. В магазине эти три расклада считает сервер по аккаунту Google Play или Apple: очистка приложения их не возвращает. На этом компьютере, пока входа нет, три расклада помнит сам браузер. Имя и день рождения считают аркан судьбы по нумерологии даты и добавляют личную строку о стихии карты. Стихии сравниваются по достоинствам Золотой зари.

В окне каждой карты есть строка Золотой зари. Для старших арканов это еврейская буква и знак, планета или стихия. Для карт от двойки до десятки — титул по «Книге Т» и декан, например «Владыка Материального Приобретения · Венера в Деве». Для тузов — «Корень сил» стихии. У Каэля первой лежит карта солнечного знака. При ней названы декан рождения и его младшая карта.

Телефон коротко вибрирует при касании, перевороте карты и конце расклада. Браузеры на iPhone вибрацию не поддерживают. Если в системе включено «уменьшить движение», нет ни анимаций, ни вибрации.

Картинки колоды ищутся в `site/cards/`. По умолчанию приложение показывает их перекрашенные копии «при свече» из `site/cards-candle/` (тёплая бумага, оранжевые акценты, тёмная рубашка); оригинал включается в разделе «Вы» → «Колода». Копии лежат отдельно, файлы в `cards/` не меняются. Картинки в `site/cards/` (`card_fool.jpg`, `card_back.jpg` и остальные, как в исходном приложении). Пока этих файлов нет, старшие арканы показываются запасными рисунками из `site/assets/cards/`, младшие — именем на рубашке стола. Скопируйте папку `cards` рядом с `site/index.html`, и подставятся ваши файлы.

## Запуск

Игру на ноутбуке открывает двойной щелчок по `site/index.html`. Браузер показывает зал сразу.

Первый ответ на расклад спрашивает модель: три абзаца своими словами по вопросу и тому, что легло. Если ключа нет, сервер молчит или модель не ответила, под картами остаётся готовый текст колоды, знаков или рун. Уточнения идут так же, через тот же сервер. Озвучки нет. Ключ в страницу не попадает. Без запущенного сервера и расклад, и уточнения дают тексты колоды.

```bash
python3 site/serve.py
```

Откройте http://127.0.0.1:41791

## Правка ответов

Живые тексты тарологов, готовых вопросов, карт, рун и знаков Линь — в `docs/otvety-kombinacii.md`. Готовый вопрос не открывает отдельный рассказ: он выбирает тему (любовь / работа / деньги / путь), и к общему значению карты подставляется строка из банка. Чтобы поправить комбинацию, в чат достаточно: таролог, вопрос, карта (или знак / руна), как должно звучать.

Ключ — одна строка в файле `site/cloudru.key`. В репозитории он пустой. Вставьте секрет туда и не выкладывайте заполненный файл обратно. Модель по умолчанию `ai-sage/GigaChat3-10B-A1.8B`. Ответ приходит текстом на экран, под картами. Озвучки нет. Пока строка пустая, остаётся короткий текст колоды.

Пока сервер запущен на вашем компьютере, выключение ноутбука гасит и страницу, и голос. Модель на cloud.ru при этом остаётся. Для магазина приложений страницу и ключ нужно держать на машине, которая не выключается.

Живой ответ сервер отдаёт только вместе с билетом расклада. Билет выдаётся аккаунту Google Play или Apple, не номеру в памяти телефона. Список аудиторий лежит в `site/store.json` (в git не входит):

```json
{
  "googleClientIds": ["веб-клиент.apps.googleusercontent.com"],
  "appleClientIds": ["идентификатор.службы.для.сайта", "com.triokna.app"]
}
```

Первый идентификатор Apple — для входа на сайте, остальные — bundle id приложения: сервер принимает любой из списка. Токен Google проверяется по ключам Google, токен Apple — по ключам Apple. Подпись чужого текста не считается аккаунтом.

Оболочка магазина передаёт вход так: `window.triOknaAccount = async () => ({ store: "google", token })` или `store: "apple"`. Для Google это ID token аккаунта, которым человек вошёл в Play. Для Apple — identity token входа Apple. Пока оболочки нет и файла `store.json` нет, текстовый ответ модели можно проверить на этом же компьютере: сервер слушает только `127.0.0.1`. На чужом адресе, например на reg.ru, модель без аккаунта магазина не вызывается.

Перед показом сервер поправляет длинную опечатку модели, если по словарю частых слов рядом есть одно явное написание. Короткие слова и имена с этого стола не меняет. Список лежит в `site/words/ru-50k.txt`.

Первый ответ идёт через `/api/reading`, когда гость открыл всё, что легло. Уточнения — через `/api/followup` по тем же картам, знакам или рунам: модели передаются вопрос, расклад и прошлые реплики. Она отвечает своими словами, тепло и с одним шагом, и не повторяет шпаргалку колоды. У карты таро в запрос уходят грани только темы стола: любовь, работа, деньги или путь человека. Внутри темы это разные механизмы, не одна сцена в чужих сферах. Планету, знак зодиака и число карты гостю не называют. У аккаунта магазина голос первого ответа сидит на билете расклада и второй расклад не тратит; на один билет — три уточнения. На этом компьютере удачный ответ модели занимает один из трёх раскладов сервера, уточнений — до девяти в день. Если модель недоступна или ключа нет, остаётся готовый текст.

## Уведомления

Пуши отправляет `site/push.py` внутри `serve.py` по стандарту Web Push, без сторонних сервисов. Ключ подписи создаётся сам при первом запуске в `site/data/vapid.pem`, подписки лежат в `site/data/push.json`. Не удаляйте `vapid.pem`: с новым ключом старые подписки перестанут работать.

Пушей всего два, и не больше одного в день, только с 10:00 до 21:00 по времени гостя:

- «Карты отдохнули» — утром после дня, когда легли все три расклада. Если гость уже зашёл сам, напоминание не придёт.
- «Новолуние / полнолуние в …» — вечером в день фазы, то есть дважды в месяц. По умолчанию выключено. Нажатие открывает лунный расклад.

Гостю предлагают уведомление в тот момент, когда карты сказали всё, а включить или выключить его можно в разделе «Вы». Разрешение браузера спрашивается только по нажатию. На iPhone пуши приходят только таверне, добавленной на экран «Домой» (iOS 16.4 и новее). На GitHub Pages сервера нет, поэтому там уведомления не включаются; нужен адрес, где работает `serve.py` по HTTPS.

## Чтобы возвращались

Всё считается на телефоне по журналу, сервер не нужен. Журнал хранит до 300 записей.

- «Как вышло?» — через 3 дня после расклада с вопросом зал спрашивает, сбылось ли: «Сбылось», «Отчасти», «Не сбылось». «Спросите позже» откладывает вопрос на 3 дня, через 60 дней таверна перестаёт спрашивать. Ответить можно и в журнале. Логика — `site/connectors/outcome.js`.
- «Ваш месяц в картах» — в разделе «Вы»: сколько карт легло за 30 дней, масти, светлые и трудные карты, карты-повторы и сколько раскладов сбылось. Появляется с пяти карт. Логика — `site/connectors/month.js`.
- Расклады новолуния и полнолуния — открыты за день до фазы, в её день и на следующий день; в зале появляется карточка, в гороскопе — ближайшая фаза. Один расклад на фазу, расклады у столов не тратит. Фазы считаются на телефоне, логика — `site/connectors/moon.js`.

Тесты: `node --test site/connectors/retention.test.js`.

## Покупки

Сейчас оплата тестовая: деньги не списываются, в окне оплаты это написано, и есть кнопка «Проверить отказ банка». Всё остальное работает как будет по-настоящему.

Лавка открывается из раздела «Вы» → «Покупки» или по ссылке на плашке отдыха. Товары, цены и правила — в `site/connectors/purchases.js`, тесты — `node --test site/connectors/purchases.test.js`. Робокасса встанет на место `createTestPayments`.
